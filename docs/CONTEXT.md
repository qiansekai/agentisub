### 1.2 角色设定与世界观

- 官方简介（引文）："自らの歌と創作で世界を表現することを夢見る、バーチャルダークシンガー。力強く儚い歌声で、"ヰ世界情緒"というキャンバスの上に闇と光、新しい物語を紡ぐ。"（憧憬以自己的歌与创作为媒介去表现世界的"虚拟暗黑歌手"。以有力而虚幻的歌声，在名为"ヰ世界情緒"的画布上织出黑暗与光、以及新的故事。）
- 她不仅演唱，还亲自进行插画、旁白（ナレーション）、配音（声优）等创作，官方称其为"唯一无二的创作者"（唯一無二のクリエイター）。这是她区别于其他成员的最大特征——神椿内同时具备"歌手 + 创作者"双重身份的存在。
- 外观视觉要素：象牙色长发、左右异色瞳（红色与蓝色的 odd-eye，中文圈亦称"异色瞳"）、遮住单眼的刘海、手套、大衣、花朵母题。
- 名字中保留了旧假名「ヰ」（读「い」），本身即是视觉与文字上的识别符号——这是翻译/听写时需特别注意的字形（不可写成「イ世界」或「井世界」）。

来源：
- https://kamitsubaki.wiki/ja/artists/vwp/isekaijoucho
- https://ja.wikipedia.org/wiki/ヰ世界情緒

### 1.3 关于"ヰ世界"与"観測者"概念

- **ヰ世界（いせかい）**：字面即"异世界"（但注意，中文圈通用译名"异世界情绪"中的"异世界"即对应"ヰ世界"）。「ヰ」是旧假名（历史假名遣），现代多用「い」替代；此处保留旧字本身即是角色名与世界观的核心符号。
- **観測者（かんそくしゃ）**：官方 WORDS 定义的粉丝总称。V.W.P 及五名成员为核心，近年也扩展为 KAMITSUBAKI STUDIO 粉丝的通称。**在翻译中应统一译作"观测者"**（来自"观测/观察世界"的世界观内核），各成员粉丝各有细分称谓（见 1.4）。
- 神椿整体世界观强调"観測"文化：观众被设定为"观测世界的人"，而非单纯的"粉丝"，这与"音楽と物語で世界を少しだけ変える"（用音乐与故事稍微改变世界）的 studio 主题一致。

来源：
- https://kamitsubaki.jp/words （官方用语集 WORDS）

## 2. 组织背景

### 2.1 KAMITSUBAKI STUDIO（神椿工作室）

- 日语：カミツバキスタジオ。有时简称"神椿"（かみつばき）。
- 由 THINKR 株式会社运营的创意厂牌（クリエイティブレーベル），以"YouTube ファースト"为方针，制作原创音乐、故事、虚拟艺人企划。
- 主题：**"音楽と物語で世界を「少しだけ」変える"**（用音乐与故事让世界"稍微"改变）。
- 2023 年组织改编后分为 4 个"厂牌内厂牌"：
  - **PHENOMENON RECORD**：以虚拟歌手为中心（V.W.P、花譜、理芽、春猿火、ヰ世界情緒、幸祜、CIEL、te'resaAI、廻花、音楽的同位体）。
  - **ANARCHIC RECORD**：创作歌手/作曲家（香椎モイミ、廉、平田義久、Empty old City）。
  - **SINSEKAI RECORD**：前身 SINSEKAI STUDIO 整合而来（VALIS、明透、雨宿り、梓川、詩道、跳亜、雄之助、MIMI、とあ、Awairo、琶舞 等）。
  - **KAMITSUBAKI CREATION**：插画/影像导演/设计师等创作者（PALOW.、川サキ、月島総記、PIEDPIPER 等）。

来源：
- https://kamitsubaki.jp/words
- https://ja.wikipedia.org/wiki/VALIS （侧栏 studio 结构）

### 2.2 V.W.P（Virtual Witch Phenomenon）

- 团名 V.W.P 全称 = **Virtual Witch Phenomenon**（"虚拟魔女现象"），中文圈常译"电脑魔女现象"或"虚拟魔女现象"。
- 成员：花譜（KAF）、理芽（RIME）、春猿火（HARU ASANUSHI）、ヰ世界情緒（ISEKAIJOUCHO）、幸祜（KOKO），共 5 名"电脑（電脳）的魔女"。
- 2021-03-14 在花譜个唱「不可解弐Q2」后结成。
- 代表曲体系：カンザキイオリ作词作曲的"系譜曲"（如「魔女」）、成员内部换组的"派生曲"、与新作曲人合作的"拡声曲"。
- 相关演出：2024-01 代々木第一体育館「現象Ⅱ」、2024-11 幕張メッセ「現象Ⅱ（再）-魔女拡成-」、2026-02 ぴあアリーナMM「現象IV-反転運命-」等。

来源：
- https://kamitsubaki.jp/artist/v-w-p
- https://ja.wikipedia.org/wiki/ヰ世界情緒

### 2.3 花譜与其他成员（神椿生态简述）

- **花譜（かふ，KAF）**：V.W.P 核心，神椿生态的起点，以「不可解」个唱系列闻名，也是"音楽的同位体 可不(KAFU)"的原型声源。
- **理芽（りめ，RIME）**：V.W.P 成员，音乐同位体「裏命(RIME)」的原型。
- **春猿火（はるさるひ，HARU ASANUSHI）**：V.W.P 成员，与ヰ世界情緒共同主持网络电台「神椿報奏部」。
- **幸祜（こうこ / 幸祜，KOKO）**：V.W.P 成员，音乐同位体「狐子(COKO)」的原型。
- **神椿市建設中。**：KAMITSUBAKI 原创 IP / 动画企划，V.W.P 五名成员担任"魔女の娘"角色配音（ヰ世界情緒 = 夜河世界 / SEKAI YORUKAWA）。

来源：
- https://kamitsubaki-anime.jp （TV 动画《神椿市建設中。》官网，CAST 表）

### 2.4 音楽的同位体（Musical Isotope，简介）

- "音楽的同位体"是 KAMITSUBAKI STUDIO 基于旗下虚拟歌手歌声制作的人工歌唱软件（歌声合成）企划，使用 CeVIO AI 引擎。
- 系列（对应原型）：
  - 可不（KAFU）← 花譜
  - 星界（SEKAI）← ヰ世界情緒（**与本项目直接相关**，见 3.3）
  - 裏命（RIME）← 理芽
  - 狐子（COKO）← 幸祜
- 另有合体单元 **V.I.P（Virtual Isotope Phenomenon）**，即"音乐同位体"的团体形态。

来源：
- https://zh.wikipedia.org/wiki/可不 （含星界、裏命、狐子的介绍）
- https://musical-isotope.kamitsubaki.jp/product/coko
